# Valuarte

Base inicial de una aplicación para artistas visuales independientes. La calculadora y la gestión de presupuestos se desarrollarán en etapas posteriores.

## Requisitos

Node.js compatible con las dependencias instaladas: actualmente `^22.22.2`, `^24.15.0` o `>=26.0.0`, y npm.

## Desarrollo

```sh
npm install
npm run dev
```

## Comprobaciones

```sh
npm run lint
npm test
npm run build
```
